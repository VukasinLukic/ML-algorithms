A collection of real-world machine learning exercises built around carefully selected Kaggle datasets.
Each task covers the full ML pipeline — from raw messy data to model evaluation — across six core algorithms.

##  Algorithms Covered

| Algorithm | Type | Focus |
|---|---|---|
| Linear Regression | Supervised | Predicting continuous values |
| K-Nearest Neighbors | Supervised | Binary classification |
| Decision Tree | Supervised | Binary classification with pruning |
| Neural Networks (MLP) | Supervised | Deep learning classification |
| K-Means | Unsupervised | Customer segmentation |
| Hierarchical Clustering | Unsupervised | Dendrogram-based grouping |

##  Datasets

Each exercise uses a different real-world dataset — insurance costs, loan approvals, wine chemistry, customer behavior, heart disease risk, and more. Datasets intentionally include missing values, outliers, and mixed data types to reflect realistic scenarios.

## What Each Exercise Covers

- Data loading and exploratory analysis
- Handling missing values (mean, median, mode imputation)
- Outlier detection and treatment (boxplots, winsorization)
- Feature selection with visualization (KDE plots, correlation matrices, countplots)
- Encoding categorical variables (one-hot, label, ordinal)
- Scaling (MinMaxScaler, StandardScaler)
- Model training and hyperparameter tuning (GridSearchCV, cross-validation)
- Evaluation (confusion matrix, precision, recall, F1, R², Silhouette Score)
- Model diagnostics (residual plots, loss curves, dendrograms, elbow method)
